# Wazuh Практикум — углублённая редакция 2

[Открыть учебный сайт](https://shayena84-byte.github.io/wazuh-praktikum-ru/)

Русскоязычный курс от основ до эксплуатации учебного SOC: **20 модулей, 80 уроков, 386 вопросов, 80 кейсов с подробными решениями и около 271 часа самостоятельной теории и практики**. Основные тексты содержат около 74 тысячслов; определения, вопросы и разборы дополняют этот объём.

Все 56 уроков первой редакции углублены. Добавлены 24 продвинутых урока: Active Directory и аудит WindowsServer2016/Win11, RouterOS7 и сетевые журналы, инженерия обнаружений, API и автоматизация, устойчивость платформы и комплексные расследования. Каждый урок содержит объяснение механизма, лабораторную, ожидаемый результат, диагностику, самостоятельный кейс, решение и проверочные вопросы.

## Если первая редакция уже пройдена

Прежние идентификаторы уроков, отметки, избранное и заметки сохранены. Ответы на старые вопросы сохраняются; итоговая оценка расширенного теста появится после ответа на добавленные вопросы. Для углублённой практики есть отдельная отметка. Можно повторно пройти основные модули или перейти к продвинутым 15–20.

## Запуск на компьютере

Требуется Python3. Из каталога проекта:

```bash
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000/. Самому сайту не нужны база данных, ключи API и установка зависимостей.

## Исходники

| Путь | Назначение |
| --- | --- |
| `build_course.py` | Первоначальные материалы 56 уроков |
| `expand_course.py` | Сборка расширений без изменения старых ID |
| `curriculum/` | Углубления, новые модули, справочник и расследования |
| `export_course.py` | Данные сайта, полный учебник, план и воспроизводимый ZIP |
| `labs/` | Исходные лабораторные материалы |
| `dist/` | Готовый статический сайт и скачиваемые материалы |
| `tests/` | Проверки переноса прогресса и фильтров расследований |

## Пересборка и проверка

```bash
python3 export_course.py
python3 validate_course.py
python3 validate_pages.py
node --check dist/app.js
node tests/progress-migration.cjs
node tests/lab-filter.cjs
python3 labs/check_fixtures.py
```

Node.js нужен только для проверки JavaScript. Валидатор проверяет полноту всех 80 уроков, глубину материала, ссылки, XML/JSON/Python и синтаксис shell-примеров. Проверка формата фикстуры не является проверкой совпадения правила на движке Wazuh. Для последней в собственном изолированном менеджере используется `labs/run_logtests.py`; сначала прочитайте `labs/README-RU.md`.

## Публикация

Settings → Pages → Source: GitHub Actions. При изменениях в `main` workflow проверяет и публикует содержимое `dist/`. Все пути поддерживают подпапку GitHub Pages. Репозиторий публичный.

## Прогресс

Данные хранятся в браузере для конкретного адреса. Экспорт и импорт находятся в разделе «Мой прогресс». Перед переносом сохраните резервный JSON; импорт заменяет локальные данные. Серверной синхронизации нет.

## Версии и пределы проверки

Учебная ветка Wazuh4.14, контрольный патч 4.14.9. Ключевые конфигурации сверены 3 ноября 2026 года по официальной документации. Ссылки `/current/` и возможности RouterOS меняются; точные требования версии указаны в соответствующих уроках. Центральные компоненты Wazuh должны иметь согласованную полную версию.

Примеры предназначены для собственного изолированного стенда. В среде подготовки курса реальная Wazuh и WindowsAD не развёртывались: результаты лабораторных описывают критерии самостоятельной проверки. Сайт использует синтетические события. Независимый учебный проект, не официальный курс и не сертификация Wazuh.
