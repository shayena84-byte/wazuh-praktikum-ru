# Wazuh Практикум

Подробный русскоязычный курс Wazuh для начинающего: **14 модулей, 56 уроков, 130 проверочных вопросов и около 121 часа теории и самостоятельной практики**.

В каждом уроке есть объяснение, пошаговое задание, ожидаемый результат, типичные ошибки, список самопроверки и вопросы с пояснениями. На сайте работают поиск, справочник, избранное, заметки и встроенный тренажёр на синтетических событиях.

**Открыть курс на GitHub Pages:** <https://shayena84-byte.github.io/wazuh-praktikum-ru/>.

## Запуск на компьютере

Требуется Python 3. В каталоге проекта выполните:

```bash
python3 -m http.server 8000 --directory dist
```

Откройте <http://localhost:8000/>. Для работы сайта не нужны Node.js, база данных, API-ключи или установка библиотек.

## Структура проекта

| Файл или каталог | Назначение |
| --- | --- |
| `dist/` | Готовый статический сайт |
| `build_course.py` | Тексты уроков и метаданные курса |
| `export_course.py` | Генерация данных сайта и отдельного плана обучения |
| `validate_course.py` | Проверка полноты курса и примеров кода |
| `validate_pages.py` | Проверка адресов файлов для корня сайта и подпапки GitHub Pages |
| `.github/workflows/pages.yml` | Проверка и автоматическая публикация GitHub Pages |

## Изменение материалов

Измените `build_course.py` и выполните:

```bash
python3 export_course.py
python3 validate_course.py
python3 validate_pages.py
```

Если изменяли JavaScript и установлен Node.js, проверьте синтаксис:

```bash
node --check dist/app.js
```

Изменения интерфейса вносятся в `dist/index.html`, `dist/style.css` и `dist/app.js`. Пути к локальным файлам относительные: сайт поддерживает размещение в корне домена и в подпапке репозитория.

## Публикация GitHub Pages

1. В настройках репозитория откройте **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Отправьте изменения в `main` или запустите workflow **GitHub Pages** вручную.

Workflow генерирует материалы, проверяет курс и синтаксис JavaScript, затем публикует содержимое `dist/`. Итоговый адрес появляется в **Settings → Pages** и в результате запуска workflow. Для бесплатного размещения через GitHub Free репозиторий должен быть публичным.

## Прогресс и заметки

Прогресс, ответы, заметки и избранное сохраняются в браузере для конкретного адреса сайта. Для переноса между разными браузерами и устройствами используйте экспорт и импорт JSON в разделе «Мой прогресс». Серверная синхронизация не предусмотрена.

## Техническая база курса

Материалы основаны на ветке **Wazuh 4.14**; сверка документации выполнена **27 октября 2026 года**. Ссылки на официальные первоисточники доступны в уроках и разделе «Источники». Страницы документации `/current/` могут меняться, поэтому перед установкой или обновлением нужно повторно проверить требования и совместимость.

Лаборатория сайта использует синтетические данные. Команды уроков предназначены для самостоятельного выполнения на описанном учебном стенде; сам сайт их не выполняет. Независимый учебный проект, не официальный курс и не сертификация Wazuh.
